# Customizable Ore Veins (NeoForge 1.21.1)

Мод добавляет 10 блоков-"жил" (iron, gold, diamond, emerald, redstone, lapis,
coal, copper, quartz, zinc). Каждая жила — это один блок-нода: при добыче он **не
исчезает**, а отдаёт немного руды за удар, пока не выдаст настроенное общее
количество (по умолчанию для железа — 1000), и только после этого
превращается в обычный камень.

## Что настраивается

При первом запуске игры/сервера создаётся файл:

```
config/oreveins-common.json
```

Для каждого типа жилы там указано:

```json
"iron": {
  "total_amount": 1000,
  "drop_item": "minecraft:raw_iron",
  "min_per_hit": 1,
  "max_per_hit": 3,
  "xp_per_hit": 0
}
```

- `total_amount` — сколько всего предметов выдаст жила, прежде чем
  превратится в камень.
- `drop_item` — id предмета, который выпадает (можно поставить айтем из
  другого мода).
- `min_per_hit` / `max_per_hit` — сколько выпадает за один удар.
- `xp_per_hit` — опыт за удар.

Меняете файл → перезапускаете игру/сервер, изменения применяются.

## Генерация в мире

Жилы генерируются в Overworld как обычная руда (через
`data/neoforge/biome_modifier/add_ore_veins.json` и
`data/oreveins/worldgen/...`). Параметры размера/частоты жил в мире сейчас
заданы фиксированно в JSON-файлах генерации (не через общий конфиг, как вы и
попросили — конфигурируются только количество руды и её тип). Если захотите
поменять частоту появления в мире, правьте
`src/main/resources/data/oreveins/worldgen/placed_feature/*.json` (поля
`count` и `height_range`) до сборки мода.

Блоки также доступны в творческом режиме — вкладка "Ore Veins".

## Сборка

```
./gradlew build
```

Готовый jar появится в `build/libs/`. Положите его в папку `mods` клиента с
NeoForge 1.21.1 (совместимая версия NeoForge указана в `gradle.properties`,
`neo_version` — при необходимости поправьте под свою установленную версию
NeoForge с neoforged.net).

Для разработки/теста:

```
./gradlew runClient
```

**Важно:** этот проект был написан и не компилировался в текущей песочнице
(нет доступа к репозиторию maven.neoforged.net из этого окружения) — при
первой сборке возможны мелкие несостыковки версий API, обычно решаются
подгонкой `neo_version` в `gradle.properties` под актуальную версию с
https://neoforged.net/. Структура кода (регистрация блоков/айтемов, логика
добычи, конфиг, worldgen) рабочая и следует стандартным паттернам NeoForge
1.21.x.

## Как добавить свой тип жилы

1. Добавить константу в `OreVeinType.java` (текстура/твёрдость берутся у
   существующего ванильного блока).
2. Добавить дефолт в `OreVeinConfig.defaultFor(...)`.
3. Сгенерировать blockstate/model json по аналогии с существующими в
   `assets/oreveins/{blockstates,models}`.
4. (Опционально) добавить configured_feature/placed_feature для генерации в
   мире и прописать в `add_ore_veins.json`.


## Автобур (работает от редстоуна)

В моде появился блок **Auto Drill** (`oreveins:auto_drill`) — выглядит как
обычный железный блок:

- Ставится где угодно. Пока на него подаётся **редстоун-сигнал** (рычаг,
  кнопка, редстоун-факел, блок редстоуна и т.д. рядом или сверху) — раз в
  секунду копает блок **прямо под собой**.
- Если под ним жила руды из этого мода — она добывается точно так же
  частями, как и при обычной добыче кайлом (используется та же логика, что
  и для игрока), и не пропадает, пока не выдаст всё, что в ней есть.
  Если под ним обычный блок (камень, земля и т.п.) — просто ломает его как
  обычно.
- Без сигнала — простаивает и ничего не делает.
- Добытое:
  1. Сначала пытается сразу перенести в инвентарь, который стоит **вплотную**
     к любой из 6 граней бура (сундук, бочка, воронка и т.д.) — это и есть
     "перенос в ближайшее хранилище": ближайшее в буквальном смысле —
     впритык к буру.
  2. Если рядом ничего нет (или всё занято) — складывает в собственный
     небольшой буфер (1 слот, до 64 предметов = 1 стак) внутри бура. Из
     этого буфера может забирать любая воронка/труба — у бура открыт
     стандартный интерфейс "инвентаря" (item handler capability).
  3. Если и буфер полон — предмет просто выпадет на землю под буром, чтобы
     ничего не терялось.

Никаких дополнительных модов для этого блока не требуется — работает на
чистом NeoForge и ванильном редстоуне.

**Важно:** так как бур копает блок прямо под собой, при постоянном питании
он будет со временем прокапывать шахту вниз (после того как под ним
закончится жила и она превратится в камень — камень тоже будет выкопан на
следующий цикл, и так далее). Если нужно, чтобы он останавливался после
конкретного блока, — отключайте питание вручную (например, редстоун-таймером
на нужное число срабатываний) или дайте знать, добавлю отдельную настройку
"копать только жилы, а не любые блоки".

## Крафт автобура

Рецепт (крафтовый стол 3x3):

```
[кусочек железа]  [ пусто ]        [кусочек железа]
[кусочек железа]  [андезитовый корпус (Create)]  [кусочек железа]
[     пусто     ]  [сундук]        [    пусто     ]
```

- Требует установленный **Create** (используется андезитовый корпус
  `create:andesite_casing`). Рецепт помечен условием `neoforge:mod_loaded`,
  поэтому он появится только если Create установлен - без Create он просто
  не загрузится, никаких ошибок не будет.
- Для игроков **без Create** есть запасной рецепт с точно таким же
  расположением, но андезитовый корпус заменён на обычный железный блок
  (`minecraft:iron_block`) - он активируется автоматически, когда Create НЕ
  установлен, так что бур всегда можно скрафтить тем или иным способом.

Файлы рецептов: `data/oreveins/recipe/auto_drill.json` (с Create) и
`data/oreveins/recipe/auto_drill_no_create.json` (без Create).

## Новые жилы: кварц и цинк

- **Кварц** (`quartz`) — обычный ванильный незеровый кварц. Генерируется
  **в Незере** (как и настоящая кварцевая руда), а не в Верхнем мире.
- **Цинк** (`zinc`) — руда из мода **Create** (`create:raw_zinc`). Работает
  и без Create в плане логики (добыча/конфиг), но текстура блока будет
  выглядеть как "битые пиксели", если Create не установлен, так как
  используется текстура их цинковой руды напрямую. Если у вас на сервере
  бывают игроки без Create - для них этот конкретный блок будет смотреться
  сломанным, остальные жилы это не касается.
